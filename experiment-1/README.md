# Experiment 1: React Application using Vite

## 📋 Description
This experiment demonstrates the development of a modern React application using Vite as a build tool. It covers the fundamentals of React component architecture, JSX syntax, state management, and efficient development workflows with hot module replacement (HMR).

## 🎯 Learning Outcomes
After completing this experiment, you will be able to:
- Understand React component architecture and component lifecycle
- Set up a React project using Vite for faster development
- Implement JSX, props, and state management using hooks
- Utilize fast refresh and HMR for improved development experience
- Build and deploy a React application
- Practice version control using Git and GitHub

## 🛠 Technologies Used
- **Frontend Framework**: React 19+
- **Build Tool**: Vite
- **Language**: JavaScript (ES6+)
- **Styling**: CSS
- **Version Control**: Git & GitHub

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
```bash
# Navigate to project directory
cd experiment-1

# Install dependencies
npm install
```

### Development
```bash
# Start development server with HMR
npm run dev

# Open your browser and navigate to http://localhost:5173
```

### Production Build
```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
